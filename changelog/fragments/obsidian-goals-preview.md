### Added

- **Obsidian Goals preview (local plugin).** Reading view renders self-contained Goals YAML in `transitrix-goals` Markdown code blocks using the shared Studio parser, validator and SVG renderer. Install from a local build; not listed in the Obsidian community catalog. Live Preview, other notations and repository views are out of scope.
- **Obsidian SVG display settings.** Shared plugin settings (node size, edge style, curvature, theme) for Reading-view SVG fences. Theme embeds via `embedCssTheme` on shared SVG renderers (Goals, Blocks, DGCA/DGA, Action, Action Card, Process Blueprint). Action Card uses theme only.
- **SVG embedCssTheme on host-neutral renderers.** `renderFgcaSvg`, `renderActivitiesSvg`, `renderActivityCardSvg`, and `renderProcessBlueprintSvg` accept optional `embedCssTheme` (default `transitrix`); high-level Goals/Blocks wrappers pass it through. VS Code live preview unchanged (body emitters + webview CSS).
- **Obsidian DGCA / DGA preview.** Reading view renders self-contained DGCA and DGA YAML in `transitrix-dgca` / `transitrix-dga` code blocks via the shared FGCA renderer. Canon projections are rejected; inline documents that only set `view_config.layers` remain allowed.
- **Obsidian Action / Blocks / Process Blueprint preview.** Reading view also renders self-contained Action, Action Card, Nested Blocks/grid, and Process Blueprint YAML via shared SVG renderers. Action Card paints the card shell without vault/canon fill.
