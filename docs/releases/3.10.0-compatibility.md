## Compatibility disposition

Compare Studio v3.9.0 (`4ad085e14e7cc9c1662e55065c183e09a42f95c6`)
with the source baseline `b5651f326f59f82155eed327ecbebd80d954fecd`.
Before #742, `relation` had no file validator and was in the registered-but-
unsupported population. An unvalidated/strict-failing input is not a previously
supported clean result. Admission and quoted lifecycle date checks therefore
add support, rather than remove supported relation-file behavior. They do not
prove catalogue identity, actor subtype, cycles or reporting health.

Methodology v7.0.0 already describes ACTOR as identity-only, with engagement and
hierarchy in first-class REL records (19-actors §1/§5 and ACTOR-003).
Rejecting inline `manager` / `reports_to` corrects previously permissive tooling;
it does not remove a field admitted by that contract. Preserve authored values
for review; never infer reporting from employment or silently move data.
Free-form `extensions` stay opaque. Existing supported employment/unit_parent
forms and admission/lifecycle positives and negatives are retained by
`tests/relation-validation.test.ts`; actor tests retain the extensions control.

These MINOR classifications concern these package contracts, independently of
Methodology's closed-enum MAJOR policy. If review produces an old-contract-valid,
previously supported counterexample, revise the affected package to MAJOR with
migration guidance before merging this preparation.

this version change and the 2.13.0 package identity, not just a branch or version
range. `requirements-build.json` embeds the build's source revision. A candidate
receipt must also record the tarball SHA-256/npm integrity, bundled diagrams
1.17.0 and emitted tool version/source revision. No artifact hash exists in this
source-only proposal. A later merge/rebuild requires its own receipt and skill
map update; do not substitute public 2.12.1 or the old 2.12.0 candidate.

Transport stays `requirements-report/1`; projection stays `requirement-chain/0.3`
with the explicit `requirement-chain/0.2` adapter retained. Keep PRODUCT and
APPLICATION identities, project/release/as-at/source provenance, unknown totals,
exact contributing IDs and the accepted UI oracle. No Phase 2 metrics are added.
